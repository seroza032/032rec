# План розробки сайту студії звукозапису

**Стек:** Vite + React + TypeScript + Tailwind CSS
**Мови:** UA / EN (перемикач)
**Тон:** молодіжний, грайливий, але не «мемний» — сучасна типографіка, темна тема, кислотний акцент, живі анімації при скролі

**Стан середовища:** папка проєкту порожня, Node/npm і Homebrew не встановлені — це враховано у Фазі 0.

---

## Фаза 0 — Середовище (30–40 хв)

Без цього нічого не запуститься.

1. Встановити Node.js через nvm (без пароля адміністратора):

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
```

2. Далі `nvm install --lts` і перевірка `node -v`, `npm -v`.
3. Ініціалізація `git init` у папці проєкту.

**Готово коли:** `npm -v` відповідає, папка під git.

---

## Фаза 1 — Каркас проєкту (1 год)

- `npm create vite@latest . -- --template react-ts`
- Tailwind CSS v4 + PostCSS, базовий `index.css` з CSS-змінними теми
- Структура:
  ```
  src/
    components/   Hero, Services, Pricing, Gallery, Contact, Footer, Nav, LangSwitch
    content/      services.ts, pricing.ts, studio.ts   ← весь текст UA+EN в одному місці
    hooks/        useLang, useScrollReveal
    assets/       photos/
  ```
- Простий i18n без бібліотеки: контент-об'єкти `{ ua: '...', en: '...' }` + React Context із перемикачем, вибір мови у `localStorage`
- ESLint/Prettier, `.gitignore`

**Готово коли:** `npm run dev` віддає порожню сторінку з робочим перемикачем UA/EN.

---

## Фаза 2 — Дизайн-система (1–2 год)

Тут задається «несерйозний, але сучасний» характер — далі все складається швидко.

- Палітра: майже-чорний фон, шумова текстура, 1 кислотний акцент (лайм / електрик-блю / гарячий рожевий — обрати один)
- Типографіка: величезні заголовки в гротеску (Space Grotesk / Unbounded), моноширинний шрифт для цін і підписів — контраст «клуб × техніка»
- Дрібні деталі характеру: анімовані бейджі, курсор-плямка, tilt на картках, «дихаючі» кнопки
- Базові UI-компоненти: Button, Tag, SectionTitle, Marquee (біжучий рядок)
- Підключення `framer-motion` + `lenis` (плавний скрол)

**Готово коли:** є сторінка-стайлгайд `/styleguide` з усіма елементами в обох темах.

---

## Фаза 3 — Головні секції: Hero + Послуги + Ціни (2–3 год)

- **Hero:** повноекранний, гігантський заголовок з анімацією появи по літерах, підзаголовок, дві CTA-кнопки (Telegram / Instagram), біжучий рядок унизу
- **Послуги:** сітка карток (запис вокалу, зведення, мастеринг, оренда, продакшн) — hover-ефект, коротке пояснення живою мовою
- **Ціни:** таблиця/картки тарифів з погодинними та пакетними цінами, позначка «популярне», примітка про знижки для постійних
- Sticky-навігація з якорями на секції

**Готово коли:** три секції наповнені реальним контентом, працюють обома мовами.

---

## Фаза 4 — Галерея з рухом фото і тексту (2–3 год)

Ключова візуальна фіча. Обрати один із трьох сценаріїв (буде прототип):

| Варіант | Як виглядає |
|---|---|
| **A. Sticky-текст + паралакс фото** | Текст «прилипає» ліворуч, праворуч повз нього пропливають знімки з різною швидкістю |
| **B. Горизонтальний скрол** | Вертикальний скрол перетворюється на горизонтальний рух стрічки фото з підписами |
| **C. Pinned-стек** | Фото накладаються стопкою в центрі, текст змінюється синхронно зі зміною кадру |

Плюс: оптимізація фото (WebP + `srcset`, lazy-load, blur-плейсхолдер), lightbox по кліку, повне відключення важких анімацій при `prefers-reduced-motion`.

**Готово коли:** галерея тримає 60 fps на телефоні й не «стрибає» при завантаженні.

## Фаза 5 — Запис на сесію та адреса (1–2 год)

- Секція бронювання: великі кнопки **Telegram** (`https://t.me/<нік>` з передзаповненим текстом через `?text=`) та **Instagram Direct**
- Плаваюча кнопка Telegram у куті на мобільних
- Блок контактів: адреса, орієнтир, години роботи, телефон (`tel:`), кнопка «Прокласти маршрут» у Google/Apple Maps
- Карта: вбудований iframe або статична картинка-заглушка з кліком у Maps (легше й швидше)
- Без бекенд-форми — заявки йдуть у месенджери, це і простіше, і звичніше аудиторії

**Готово коли:** з телефона кнопка відкриває чат із готовим текстом, маршрут будується в один тап.

---

## Фаза 6 — Поліш і мікровзаємодії (1–2 год)

- Reveal-анімації секцій при вході у в'юпорт, стагер елементів
- Стани hover/active/focus, плавні переходи, звук-плеєр із демо-треками студії (опційно, з mute за замовчуванням)
- 404-екран, favicon, OG-зображення для гарного прев'ю в Telegram/Instagram

---

## Фаза 7 — Адаптив, продуктивність, SEO (1–2 год)

- Перевірка на 375 / 768 / 1440 px, реальний тест у мобільному браузері
- Lighthouse: ціль ≥ 90 за Performance та Accessibility
- `<title>`, meta description, OG/Twitter-теги, `hreflang` для UA/EN, JSON-LD `LocalBusiness` (адреса, години, ціновий діапазон) — щоб студія гарно виглядала в пошуку та на картах
- Alt-тексти, контраст, навігація з клавіатури

---

## Фаза 8 — Деплой (30–40 хв)

- Білд + деплой на Netlify або Vercel (безкоштовно, HTTPS, автодеплой із git)
- Підключення власного домену, якщо є
- Коротка інструкція, як самому міняти ціни й фото — редагується один файл `src/content/pricing.ts`
